# Lohnrechner PWA

Eine moderne Web-App / Progressive Web App (PWA) zur einfachen Berechnung des Monatslohns aus Stundenlohn, gearbeiteten Stunden und Zusatzeinnahmen.

## Funktionen
- 📊 **Stunden- & Lohnberechnung:** Übersichtliche Darstellung von gearbeiteten Stunden, Grundlohn und Gesamteinnahmen.
- 📅 **Monats- & Tagesverwaltung:** Detaillierte Tageseinträge und historische Monatsübersicht.
- 🌗 **Dark / Light Mode:** Automatische oder manuelle Anpassung an das Design.
- 📱 **PWA & Offline-Fähigkeit:** Service Worker zur schnellen Offline-Nutzung und Installation als App.
- 🔇 **Stumm geschaltet:** Kein Ton beim Starten oder Klicken.

## Installation & Deployment
1. Lade dieses Repository herunter oder klone es zu GitHub.
2. Aktiviere **GitHub Pages** in den Repository-Einstellungen (`Settings` -> `Pages` -> Source: `main` Branch).
3. Öffne die generierte URL auf deinem Smartphone oder Browser.
